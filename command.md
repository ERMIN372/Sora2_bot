# Команды Telegram-бота

Ниже перечислены все slash-команды, зарегистрированные в обработчиках бота, с кратким описанием их работы и ограничений.

| Команда | Что делает | Дополнительные условия |
| --- | --- | --- |
| `/start` | Сбрасывает состояние диалога, гарантирует наличие пользователя в БД и отправляет главное меню. | Доступна всем пользователям. |
| `/help` | Показывает справку с описанием доступных моделей и клавиатурой помощи. | Доступна всем пользователям. |
| `/status` | Отображает результат последней проверки работоспособности сервиса. | Только для администраторов. |
| `/diag` | Выводит сведения о последней зарегистрированной ошибке, включая идентификаторы и сообщения. | Только для администраторов. |
| `/job <corr_id>` | Находит и выводит историю событий по указанному идентификатору корреляции. | Только для администраторов. |
| `/models` | Собирает и выводит список доступных моделей генерации (Gemini и Sora 2), а также ошибки загрузки. | Требует соответствующих интеграций; доступна всем пользователям. |
| `/video_models` | Получает перечень видеомоделей OpenAI Sora 2 и выводит его пользователю. | Работает, когда включена интеграция Sora 2. |
| `/video_list` | Показывает последние задания генерации видео с параметрами запроса и статусами. | Работает, когда включена интеграция Sora 2. |
| `/video_info <video_id>` | Загружает подробную информацию о конкретном видео и возвращает её пользователю. | Работает, когда включена интеграция Sora 2. |
| `/video_create <описание>` | Создаёт запрос на генерацию нового видео, регистрирует задачу и сообщает её параметры. | Требует активной Sora 2, достаточного баланса и корректного промпта. |
| `/video_remix <video_id> [параметры]` | Запускает ремикс уже созданного видео с учётом дополнительных настроек и списывает кредиты. | Требует активной Sora 2, наличия видео и достаточного баланса. |
| `/video_get <video_id> [формат]` | Скачивает видео напрямую через провайдера и отправляет файл в чат. | Только для администраторов и при доступном провайдере скачивания. |
| `/diag_openai_video` | Выполняет диагностику интеграции с OpenAI Videos API и выводит собранные показатели. | Работает, когда включена интеграция Sora 2. |
| `/balance` | Показывает текущий баланс кредитов пользователя. | Доступна всем пользователям. |
| `/pro` | Сообщает, что PRO-режим недоступен, если пользователь запрашивает его. | Доступна всем пользователям. |
| `/buy_card` | Открывает витрину пополнения инициализируя меню оплаты. | Доступна всем пользователям. |

> Эти команды регистрируются в `handlers.register_handlers`, поэтому доступны пользователям бота при использовании соответствующих slash-запросов в Telegram.
